Date: 2026-10-06. Static source review only; no tests, deployment, Oracle SQL, or runtime experiment was performed.

## Flyway and Oracle compile scope

A case-insensitive search of the pinned ODC source tree found no Flyway library or Flyway integration for Oracle target changes. ODC's own `server/odc-core/.../migrate` package is a separate internal metadata-schema migration mechanism. This scoped absence does not prove that no external integration is possible. A Flyway CLI pipeline can be evaluated as the sole DDL executor, with ODC used for request/review/approval only if ODC's task can avoid executing the same DDL. Do not let both systems execute a release.

The source distinguishes `ORACLE` from `OB_ORACLE`. ODC includes an OceanBase Oracle PL/SQL lexer and its `DBPLService` offers PL compile behavior through an ODC database session, but that is not proof that the async Oracle migration worker verifies native Oracle compilation status. It cannot certify compatibility with an unspecified Oracle release. See [`DBPLService`](https://github.com/oceanbase/odc/blob/d517c0f27971642fb0cd7565fd61ab2309875ec3/server/odc-service/src/main/java/com/oceanbase/odc/service/db/DBPLService.java#L196-L245) and [`DialectType`](https://github.com/oceanbase/odc/blob/d517c0f27971642fb0cd7565fd61ab2309875ec3/server/odc-core/src/main/java/com/oceanbase/odc/core/shared/constant/DialectType.java#L20-L65).

## Decision relevance for a 50-instance, 20-account estate

The source contains ordered multi-database async rollout logic ([`MultipleDatabaseChangeRuntimeFlowableTask`](https://github.com/oceanbase/odc/blob/d517c0f27971642fb0cd7565fd61ab2309875ec3/server/odc-service/src/main/java/com/oceanbase/odc/service/flow/task/MultipleDatabaseChangeRuntimeFlowableTask.java#L122-L188)), which is relevant to reducing repeated manual submission. It does not establish target migration history, checksum enforcement, crash reconciliation, or separated execution identity. Thus ODC can merit a bounded governance/rollout evaluation, but this survey alone does not justify using it as the migration system of record for the 50 Oracle targets.
